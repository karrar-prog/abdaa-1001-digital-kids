# منصة حفل تخرج مبادرة «1001» طفل رقمي
## نادي أبدع للمهارات الذكية – النجف الأشرف

منصة تفاعلية متكاملة لإدارة حفل تخرج الدفعة الأولى من مبادرة **1001 طفل رقمي** المقامة في **قصر الثقافة بالنجف الأشرف**.

---

### ✨ المميزات الرئيسية للموقع:
1. **تصميم سينمائي ذكي وعصري (Creative Tech)**: هوية بصرية مخصصة لأطفال الذكاء الاصطناعي والروبوتات تجمع بين الفخامة والروح الحيوية.
2. **نظام تأكيد الحضور والتذاكر (RSVP & E-Ticket)**:
   - نموذج تسجيل لضيوف الحفل وعائلات الأطفال الخريجين.
   - توليد فوري لتذكرة إلكترونية رسمية بـ **QR Code** فريد ورقم تذكرة (ABD-XXXX).
   - إمكانية طباعة التذكرة أو حفظها كـ PDF.
3. **بوابة المنظمين والتحقق الميداني (Check-in Scanner)**:
   - فحص وتأكيد الدخول الميداني عند أبواب قصر الثقافة.
   - منع تكرار الدخول وتحديث عداد الحضور الفعلي لحظة بلحظة.
4. **معرض الـ 40 مشروعاً ابتكارياً (Interactive Expo)**:
   - استعراض حي لمشاريع الأطفال في الروبوتات والذكاء الاصطناعي والبرمجة والأمن السيبراني.
   - إمكانية البحث والفلترة وفتح نافذة تفاصيل كل مشروع وفريقه.
5. **جدول المنهاج الزمني الدقيق (Timeline Agenda)**:
   - تسلسل فقرات الحفل من الاستقبال وحتى تتويج الـ 170 طفلاً وتكريم المدربين والشركاء.
6. **بوابة الشراكات والمتطوعين**:
   - استمارات إلكترونية لطلب الرعاية، والفرق التطوعية.
7. **الربط مع Supabase السحابي**:
   - الموقع يعمل حالياً بنظام تخزين محلي ذكي (بدون الحاجة لإنترنت أو دفع مال).
   - يتوفر ملف `supabase_schema.sql` لربط قاعدة البيانات بضغطة زر واحدة مجاناً.

---

### 🚀 تشغيل الموقع:
يمكنك تشغيل الموقع فوراً عبر الضغط مرتين على ملف:
`تشغيل_الموقع.bat`

أو عبر سطر الأوامر:
```bash
npm run dev
```
ورابط الموقع المباشر:
`http://localhost:3000`
